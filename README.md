# Portfolio de Gabriel Alvarez

Sitio estático listo para publicarse en GitHub Pages.

## Editar contenido

Los textos principales están en `index.html`.

## Vista previa local

Abre `index.html` en tu navegador.

## Publicar en GitHub Pages

1. Verifica que el repositorio se llame `alvarogabriel-ramirez.github.io`.
2. Guarda tus cambios.
3. Ejecuta:

```powershell
git add .
git commit -m "Crear portfolio profesional"
git push origin main
```

4. Espera entre 1 y 5 minutos.
5. Abre:

`https://alvarogabriel-ramirez.github.io`

## Si no aparece el sitio

1. En GitHub entra a `Settings`.
2. Luego entra a `Pages`.
3. En `Build and deployment`, selecciona:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
4. Guarda los cambios y espera a que GitHub publique la página.
